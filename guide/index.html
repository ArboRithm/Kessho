Introduction ​

Kessho est une application de bureau qui tient une mémoire structurée pour vos agents IA : un dossier de fichiers Markdown qui vous appartient. Une mémoire simple et plate, où l'on empile des notes, grossit sans contrôle ; celle de Kessho est rangée en zones, en projets et en domaines, avec des résumés et des archives, pour que sa croissance reste maîtrisée. Vos agents IA la lisent et l'enrichissent ; l'application, elle, vous la montre, la range et vous laisse la modifier. Ce guide décrit l'application, écran par écran.

Les captures d'écran de ce guide montrent une mémoire de démonstration fictive.

Les idées à connaître ​

La mémoire. C'est un simple dossier sur votre disque. Il est portable : vous pouvez le copier, le sauvegarder, l'ouvrir avec d'autres outils. Il est compatible avec Obsidian, sans en dépendre.

Les notes. Chaque note est un fichier Markdown. Kessho les range dans des zones, qui disent à quoi sert une note : une session, un savoir, une procédure, un principe, un objectif, une personne… Voir Zones.

Les projets et les domaines. Une note se rattache à un projet ; un domaine est un périmètre transversal qui réunit plusieurs projets, et un projet peut appartenir à plusieurs domaines (voir Zones). Chacun porte un résumé que vous pouvez donner à un agent pour reprendre le travail : ce sont les clés de contexte (voir Accueil).

Les agents. Votre assistant IA parle à la mémoire par un serveur MCP, kessho-mcp, livré avec l'application. Kessho le déclare dans les assistants installés sur votre poste (voir Connecter ses agents). Ce que l'agent écrit apparaît dans l'application ; ce que vous modifiez dans l'application, l'agent le lit.

Écran par écran

  • Accueil : l'état de la mémoire d'un coup d'œil, et les clés de contexte.
  • Zones : parcourir, filtrer et ranger les notes.
  • Atome et éditeur : lire et écrire une note.
  • Graphe : voir les relations entre les notes.
  • Synchronisation : sauvegarder la mémoire avec git.
  • Réglages : apparence, mémoire, connecteurs.
  • Aide : trouver de l'aide dans l'application.

Et avec un agent ? ​

Ce guide parle de ce que vous faites avec la souris et le clavier. Pour ce que vous demandez à votre agent — reprendre une session, archiver, chercher —, voir Avec un agent. Les outils eux-mêmes sont décrits dans la Référence MCP.
