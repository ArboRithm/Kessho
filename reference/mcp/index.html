Référence MCP ​

Cette référence décrit les outils que le serveur MCP de Kessho expose à vos agents : leur nom, ce qu'ils font, leurs paramètres. Elle est dérivée du catalogue du serveur (la réponse à tools/list du binaire kessho-mcp) : elle ne peut pas décrire un outil qui n'existe plus, et un outil ajouté la rend périmée tant qu'elle n'est pas régénérée.

Lire une page ​

Chaque famille a sa page ; chaque outil y a sa section, nommée comme l'outil appelé par l'agent :

  • la description, telle que le catalogue l'écrit — en français, sur les deux versions du site ;
  • le tableau des paramètres : nom, type, requis ou non, description du catalogue ;
  • en tête de page, des exemples : la phrase que vous dites à l'agent, puis l'appel qu'il en tire.

Vous n'avez pas besoin d'appeler ces outils vous-même : l'agent les choisit selon ce que vous demandez. Pour savoir quoi dire, lisez Avec un agent.
