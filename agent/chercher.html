Chercher dans la mémoire ​

Ce parcours sert à retrouver une décision, une note, ce que la mémoire sait d'un fichier, ou le fil des dernières sessions. Tout y est en lecture : aucune recherche n'écrit dans la mémoire (sauf l'ajout d'alias, signalé plus bas).

Ce que vous demandez à l'agent ​

Vous demandez à l’agent

« Où a-t-on parlé de la synchronisation Git ? Cherche dans toute la mémoire. »

→ L’agent appellemem_search
  • query = synchronisation git
  • limit = 10
Vous demandez à l’agent

« Cherche « scellé » dans les connaissances seulement, archives comprises. »

→ L’agent appellemem_search
  • query = scell
  • zone = 20-knowledge
  • include_archived = true
Vous demandez à l’agent

« Avant de modifier ce fichier, dis-moi ce que la mémoire en sait : src/domain/session.rs. »

→ L’agent appellemem_about_path
  • path = src/domain/session.rs
Vous demandez à l’agent

« Montre-moi ce qui est relié à la note 20-knowledge/runner, sur deux niveaux. »

→ L’agent appellemem_relations
  • path = 20-knowledge/runner
  • depth = 2
Vous demandez à l’agent

« Résume les cinq dernières sessions de kessho-docs. »

→ L’agent appellemem_digest
  • slug = kessho-docs
  • n = 5
Vous demandez à l’agent

« Ajoute à la note 20-knowledge/runner les mots « ça saccade sur téléphone ». »

→ L’agent appellemem_alias_add
  • path = 20-knowledge/runner
  • aliases = ["ça saccade sur téléphone"]

Une question sur le passé (« qu'avait-on décidé sur… ? », « où a-t-on parlé de… ? ») suffit à ce que l'agent cherche : les procédures livrées (voir Connecter l'agent) l'y invitent.

Ce que fait l'agent ​

  1. Chercher du texte. mem_search cherche dans tout le vault et rend une correspondance par ligne, avec son contexte. Le motif query est une expression régulière. Les options, toutes facultatives :
    • case_insensitive : ignorer la casse (oui par défaut) ;
    • fold_accents : « reglage » trouve « réglage » (oui par défaut) ;
    • fold_separators : espaces, tirets et soulignés interchangeables, « deploy kit » trouve deploy-kit ; sans effet si le motif contient un métacaractère de regex (oui par défaut) ;
    • search_names : le nom du fichier compte aussi, ces correspondances portent line_number 0 (oui par défaut) ;
    • zone : se limiter à une zone (00-inbox, 10-episodes, 20-knowledge…) ;
    • include_archived : inclure 10-episodes/archived/, exclu par défaut ;
    • limit : 50 correspondances par défaut, 500 au plus.
  2. Savoir ce que la mémoire connaît d'un fichier. mem_about_path prend le chemin d'un fichier du dépôt de code, relatif à sa racine (un chemin absolu est refusé), et rend ce que le vault en sait : les faits de la carte qui le décrivent, le manifeste qui a établi sa technologie, le document de cadrage qui le concerne. Le catalogue demande de l'appeler avant de toucher un fichier qu'on ne connaît pas. Ne rien savoir n'est pas une erreur : la réponse dit alors combien de notes citent un fichier quelconque.
  3. Suivre les liens d'une note. mem_relations prend le chemin d'une note (relatif au vault, avec ou sans .md) et rend ce qui est plus général (up), plus précis (down) et voisin (side). direction vaut up, down, side ou all (défaut) ; depth va de 1 à 6 (défaut 2). Au-delà de 200 notes, le résultat est marqué tronqué ; les liens dont la cible n'existe pas sont nommés.
  4. Le fil des sessions. mem_digest résume les n archives les plus récentes d'un projet (5 par défaut, 50 au plus) : date, sujet, extrait. Un projet archivé n'est résumé qu'avec from_archived: true. Pour lire une archive entière, voir mem_read_archive dans Reprendre un projet.
  5. Le graphe entier. mem_graph_export exporte les notes et leurs relations ; la charge est volumineuse, levels ne garde que les niveaux demandés (domaine, concept, projet, note, archive).
  6. Aider à retrouver. mem_alias_add écrit : il ajoute à une note des alias en langue de tous les jours (le symptôme, le besoin) pour qu'on la retrouve avec ces mots. Les alias déjà présents ne sont jamais perdus.

Ce que vous voyez ​

Une recherche d'agent ne change rien à l'écran : le résultat est dans la conversation avec votre agent. L'application a ses propres moyens de retrouver une note : Chercher dans la barre latérale (voir Accueil) et le graphe.

Seul mem_alias_add écrit : il allume le témoin de fraîcheur comme toute écriture d'agent (voir Zones).
