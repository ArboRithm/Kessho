Maintenance ​

These tools maintain the memory rather than enrich it: audit its hygiene, list and repair findings, maintain the codebase map, migrate the schema or move the vault, check the available version, get command help.

Four only read (mem_health_scan, mem_health_tasks, mem_check_update, mem_help). mem_health_repair, mem_codebase_repair and mem_migrate are dry runs unless apply: true; mem_vault_migrate is one unless confirm: true; it moves the whole vault, .git included, and no commit follows it. mem_codebase_scan is read-only on the map's content, but advances its own anchor in topology.md.

To ask for them by talking to your agent, see Maintain the memory.

In practice ​

You ask your agent

« Run a health check of the memory. »

→ The agent callsmem_health_scan
You ask your agent

« Show me what the automatic repair would fix, without writing anything. »

→ The agent callsmem_health_repair

The tools ​

mem_health_scan ​

Audits the vault's hygiene across all its categories; read-only, and each finding says which repair stage handles it (app, agent or none).

Catalog description (French, verbatim):

Audite l'hygiène du vault sur toutes ses catégories, énumérées au schéma. Lecture seule : aucune écriture, en aucune circonstance. Chaque constat porte son étage de réparation — stage : app (mem_health_repair le répare), agent (task_id, voir mem_health_tasks) ou none (reason dit pourquoi) — et by_stage les compte. Les catégories non évaluées sont nommées avec leur motif.

Paramètre / ParameterTypeRequis / RequiredDescription (catalogue)
categorystringnon / noRestreint l'audit à une seule catégorie. L'une de : malformed-frontmatter | stray-zone-md | empty-md-at-root | missing-zone-index | missing-display | dangling-wikilinks | orphan-atoms | missing-archeo-hashes | mcp-tool-spec-drift | skill-description-too-long | missing-zone-index-entry | missing-universal-frontmatter | missing-archeo-context-origin | archeo-derived-orphan | topology-archives-out-of-sync | archeo-archive-incomplete-frontmatter | non-canonical-slug | legacy-slug-filename | stale-repo-topology-path | stale-codebase-map | frontmatter-key-hors-schema | contexte-sans-resume | orphan-images | unclassified-note | unresolved-relation | concept-cycle. Absent = toutes.

mem_health_tasks ​

Lists the health plan's agent tasks, the findings that need judgment, each with its problem, measured hints, the MCP tools to use and its completion criterion; read-only.

Catalog description (French, verbatim):

Liste les tâches d'agent du plan de santé : les constats qui demandent du jugement — résumé à composer, atome orphelin à rattacher, wikilien sans cible sûre, conflit de fusion, dépôt déplacé. Chaque tâche porte le problème, les indices mesurés (candidats lexicaux classés), les outils MCP à employer et son critère de fin : le constat disparaît de mem_health_scan. Lecture seule. Traiter chaque tâche avec les outils qu'elle nomme, puis relancer mem_health_scan pour vérifier.

Paramètre / ParameterTypeRequis / RequiredDescription (catalogue)
cursorstringnon / noIdentifiant de la dernière tâche reçue (next_cursor de l'appel précédent) : les tâches sont rendues par identifiant croissant, et la page suivante commence après lui.
kindstringnon / noRestreint à un genre : compose-summary | attach-orphan | resolve-wikilink | resolve-merge-conflict | locate-repo | review-frontmatter-key. Absent = tous.
limitintegernon / noNombre maximal de tâches rendues (défaut 30).

mem_health_repair ​

Applies the safe, deterministic fixes of the health plan, finding by finding; a dry run by default that returns a plan_id, and apply: true requires that plan_id.

Catalog description (French, verbatim):

Applique l'étage app du plan de santé : les correctifs dont la réponse est unique et sûre, constat par constat. Catégories dotées d'un réparateur déterministe : missing-display, missing-zone-index-entry, non-canonical-slug, missing-universal-frontmatter, orphan-atoms, frontmatter-key-hors-schema, dangling-wikilinks, topology-archives-out-of-sync, stale-repo-topology-path, missing-archeo-context-origin — un constat dont la condition de sûreté ne tient pas descend à l'étage agent ou reste signalé, jamais réparé au mieux. À blanc par défaut : la réponse porte plan_id, planned_fix_count, files_to_modify et planned — rien n'est écrit. apply: true écrit, avec le plan_id du plan à blanc OBLIGATOIRE — sans lui, ou si le plan a changé entre-temps, rien n'est écrit — et répond fixes_applied, files_modified, failed. Tout autre paramètre (dry_run compris) est refusé. Rien n'est jamais supprimé.

Paramètre / ParameterTypeRequis / RequiredDescription (catalogue)
applybooleannon / noFaux (défaut) : rendre le plan sans rien écrire. Vrai : appliquer les correctifs.
plan_idstringnon / noObligatoire avec apply : l'empreinte rendue par le plan à blanc. Absente, ou si le plan a changé depuis, rien n'est écrit.

mem_codebase_scan ​

Diagnoses one project's codebase map: last scan anchor, coverage, stale entries, dead references and undescribed candidates; read-only on the map's content, but it advances its own anchor in topology.md.

Catalog description (French, verbatim):

Diagnostique la carte de codebase d'UN projet : ancre du dernier scan, couverture (fichiers décrits sur fichiers suivis par Git), entrées périmées (contenu changé), références mortes (fichier disparu), candidats non décrits (touchés depuis la dernière ancre, aucune entrée). Lecture seule sur le contenu de la carte ; avance sa propre ancre sur topology.md.

Paramètre / ParameterTypeRequis / RequiredDescription (catalogue)
projectstringoui / yesSlug du projet à diagnostiquer.

mem_codebase_repair ​

Mechanically repairs one project's codebase map by removing a dead reference when the entry keeps at least one living citation; never touches a stale entry; a dry run unless apply is true.

Catalog description (French, verbatim):

Répare mécaniquement la carte de codebase d'UN projet : retire une référence morte (fichier disparu) SI l'entrée garde au moins une autre citation vivante. Ne touche JAMAIS une entrée périmée (contenu changé) : sautée avec son motif, comme un fichier qui serait sa seule citation. À blanc par défaut — apply est requis pour écrire.

Paramètre / ParameterTypeRequis / RequiredDescription (catalogue)
applybooleannon / noFaux (défaut) : décrire le plan sans rien écrire. Vrai : appliquer.
projectstringoui / yesSlug du projet à réparer.

mem_migrate ​

Runs, in order, the schema migrations whose target version is above the vault's; a dry run unless apply is true, and a backup precedes any application unless explicitly waived.

Catalog description (French, verbatim):

Traverse les migrations de schéma dont la version cible dépasse celle du vault, dans l'ordre. À blanc par défaut — apply est requis pour écrire. Une sauvegarde précède toute application, sauf renoncement explicite, et une étape en échec arrête la chaîne.

Paramètre / ParameterTypeRequis / RequiredDescription (catalogue)
applybooleannon / noFaux (défaut) : décrire les étapes sans rien écrire. Vrai : les appliquer.
skip_backupbooleannon / noVrai : renoncer à la sauvegarde préalable du vault. À n'employer qu'en connaissance de cause, ou quand le vault dépasse le plafond de sauvegarde automatique.

mem_vault_migrate ​

Moves the whole vault to a new location, then makes the application configuration, the per-client memory-kit.json files, Claude Code's allowed directories and the deployed MCP clients' --vault argument follow; a dry run unless confirm is true, and no commit follows it since it moves the whole vault, .git included.

Catalog description (French, verbatim):

Déplace le vault entier vers un nouvel emplacement, puis fait suivre la configuration de l'application, les sept memory-kit.json par client, les répertoires autorisés de Claude Code et l'argument --vault des clients MCP déployés. Toutes les cibles d'écriture sont validées AVANT le moindre mouvement. À blanc par défaut — confirm est requis.

Paramètre / ParameterTypeRequis / RequiredDescription (catalogue)
confirmbooleannon / noFaux (défaut) : rendre le plan sans rien muter. Vrai : déplacer et réécrire.
targetstringoui / yesEmplacement d'arrivée du vault, en chemin absolu.

mem_check_update ​

Compares this binary's version with the latest one published by the project's repository; the result is cached for an hour, and a missing or slow network yields a reason, never an error.

Catalog description (French, verbatim):

Compare la version de ce binaire à la dernière publiée par le dépôt du projet. Cache d'une heure, appel borné en délai, renoncement par variable d'environnement. Un réseau absent ou lent rend un motif, jamais une erreur.

Paramètre / ParameterTypeRequis / RequiredDescription (catalogue)
force_refreshbooleannon / noVrai : ignorer le cache et interroger le réseau.

mem_help ​

Returns the inventory of tools grouped by category, or the help of one command (its description, parameters and neighbours), derived from the catalog.

Catalog description (French, verbatim):

Rend l'inventaire des outils groupés par catégorie, ou l'aide d'une commande : sa description, ses paramètres et ses voisines. Dérivée du catalogue, elle ne peut pas diverger de ce que le serveur expose.

Paramètre / ParameterTypeRequis / RequiredDescription (catalogue)
commandstringnon / noCommande dont rendre l'aide, sous l'une ou l'autre forme (mem_help ou mem-help). Absente = l'inventaire général.
langstringnon / noLangue du chrome : en, fr, es, de ou ru. Absente ou inconnue = anglais.
