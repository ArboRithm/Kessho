MCP reference ​

This reference describes the tools that Kessho's MCP server exposes to your agents: their name, what they do, their parameters. It is derived from the server's catalog (the tools/list answer of the kessho-mcp binary): it cannot describe a tool that no longer exists, and an added tool makes it stale until it is regenerated.

Reading a page ​

Each family has its page; each tool has its section there, named like the tool the agent calls:

  • an English summary of one sentence, written for this site;
  • the description, as the catalog writes it — in French, because the catalog is only written in French and is not translated here;
  • the parameter table: name, type, required or not, catalog description;
  • at the top of the page, examples: the sentence you say to the agent, then the call it makes from it.

You do not need to call these tools yourself: the agent chooses them from what you ask. To know what to say, read With an agent.
