Repository archaeology ​

These tools rebuild the memory of an already written repository, in phases: framing and file listing (phase 0), reading and synthesis (phase 1), technical stack (phase 2), Git history (phase 3). mem_archeo orchestrates them.

Three only read: mem_archeo_plan, mem_archeo_index_files, mem_archeo_context. mem_archeo_project_topology, mem_archeo_context_finalize, mem_archeo_stack and mem_archeo_git write; in branch-first mode, mem_archeo writes nothing until its plan has been acknowledged.

mem_archeo_atlassian is declared but always refuses, by design: Confluence and Jira retro-archiving goes through the client-side Atlassian MCP.

In practice ​

You ask your agent

« Frame a reconstruction of this repository's history, writing nothing: /Users/ben/Projets/Kessho. »

→ The agent callsmem_archeo_plan
  • repo_path = /Users/ben/Projets/Kessho

The tools ​

mem_archeo ​

Orchestrates the whole repository archaeology: one topology scan shared by the stack resolution and the history reconstruction, then the reading briefing of phase 1; in branch-first mode it returns the plan and writes nothing until the plan is acknowledged.

Catalog description (French, verbatim):

Orchestrateur de l'archéologie : un seul scan de topologie, partagé par la résolution de pile et la reconstruction d'histoire, puis le briefing de lecture de la Phase 1. En mode branche d'abord, rend le plan et n'écrit rien tant qu'il n'a pas été validé.

Paramètre / ParameterTypeRequis / RequiredDescription (catalogue)
acknowledged_via_planbooleannon / noDOIT valoir vrai pour toute invocation en mode branche d'abord. Tant qu'il est faux, l'orchestrateur rend le plan SANS aucune écriture, pour que l'appelant le fasse valider par l'utilisateur. Rappelez ensuite avec ce jeton à vrai.
branch_basestringnon / noBranche de base pour la divergence. Défaut : main.
branch_firststringnon / noRestreindre la Phase 3 aux commits propres à cette branche. Active le mode branche d'abord et sa garde de cadrage.
by_authorbooleannon / noScinder chaque fenêtre par auteur principal.
by_filesbooleannon / noInterroger les commits touchant les fichiers introduits par la branche, à l'échelle du dépôt.
depthintegernon / noEnregistré dans la topologie, sans effet sur le parcours, qui est de premier niveau. Borné à [1, 4], défaut 2.
levelstringnon / noGranularité de la Phase 3 : 'tags' (défaut), 'releases', 'merges' ou 'commits'.
projectstringnon / noSlug du projet d'accueil. Déduit du nom du dossier du dépôt s'il correspond à un projet existant.
repo_pathstringoui / yesChemin absolu du dépôt Git local.
sincestringnon / noBorne basse de la Phase 3, AAAA-MM-JJ.
since_datestringnon / noAncre explicite : date plancher, AAAA-MM-JJ.
since_shastringnon / noAncre explicite : SHA de départ.
untilstringnon / noBorne haute de la Phase 3, AAAA-MM-JJ.
windowstringnon / noPour level='commits' : 'day', 'week' (défaut) ou 'month'.

mem_archeo_plan ​

Phase 0 of the archaeology: frames a branch-first reconstruction (slug, project, scope, granularity, filters and the next call to make); read-only.

Catalog description (French, verbatim):

Phase 0 de l'archéologie : cadrage d'une reconstruction en mode branche d'abord — slug, projet, portée, granularité, filtres et appel suivant. Lecture seule.

Paramètre / ParameterTypeRequis / RequiredDescription (catalogue)
branchstringnon / noBranche à cadrer. Défaut : la branche courante.
branch_basestringnon / noBranche de base pour la divergence. Défaut : détectée via origin/HEAD, puis par sondage de main, master, develop.
projectstringnon / noImpose le slug du projet et court-circuite l'heuristique. À n'employer que si le slug ne doit PAS suivre le nom de branche.
repo_pathstringoui / yesChemin absolu du dépôt Git local.

mem_archeo_project_topology ​

Phase 1 of the archaeology: writes the project's topology note from the LLM client's synthesis and rewrites the context.md sections it feeds; refuses until the reading has been acknowledged.

Catalog description (French, verbatim):

Phase 1 de l'archéologie : écrit l'atome de topologie du projet depuis la synthèse du client LLM, et réécrit les sections de context.md qu'elle alimente. Refuse tant que la lecture n'est pas accusée.

Paramètre / ParameterTypeRequis / RequiredDescription (catalogue)
acknowledged_via_readbooleannon / noDOIT valoir vrai, après que chaque fichier de files_to_read a été lu. Sans ce jeton, l'appel est refusé : c'est la seule barrière contre l'extraction sans lecture.
projectstringoui / yesSlug du projet, tel qu'il figure sous 10-episodes/projects/.
synthesisobjectoui / yesSynthèse conforme au schéma rendu par mem_archeo_context. Clés : components, domain_concepts, patterns, decisions, risks_or_friction — chacune peut être vide.

mem_archeo_git ​

Phase 3 of the archaeology: rebuilds a repository's history as dated archives, one per milestone (tags, releases, merges or commit windows), and makes sure the host project has its skeleton.

Catalog description (French, verbatim):

Phase 3 de l'archéologie : reconstruit l'histoire d'un dépôt en archives datées, une par jalon, et garantit que le projet d'accueil porte son squelette.

Paramètre / ParameterTypeRequis / RequiredDescription (catalogue)
branch_basestringnon / noBranche de base pour la divergence. Défaut : main.
branch_firststringnon / noRestreindre la portée aux commits propres à cette branche. Active le mode branche d'abord.
by_authorbooleannon / noScinder chaque fenêtre par auteur principal. Imposé en mode branche d'abord.
by_filesbooleannon / noInterroger les commits touchant les fichiers introduits par la branche, à l'échelle du dépôt. Capture la lignée complète, correctifs postérieurs à la fusion compris.
levelstringnon / noGranularité : 'tags' (défaut, étiquettes semver), 'releases' (publications GitHub, via gh), 'merges' (demandes de tirage fusionnées, via gh) ou 'commits' (fenêtres de temps).
projectstringnon / noSlug du projet d'accueil. Déduit du nom du dossier du dépôt s'il correspond à un projet existant ; le squelette est initialisé si le slug est donné explicitement.
repo_pathstringoui / yesChemin absolu du dépôt Git à parcourir.
sincestringnon / noBorne basse incluse, AAAA-MM-JJ.
since_datestringnon / noAncre explicite : date plancher, AAAA-MM-JJ.
since_shastringnon / noAncre explicite : SHA de départ, court-circuite la base commune.
untilstringnon / noBorne haute incluse, AAAA-MM-JJ.
windowstringnon / noPour level='commits' : 'day', 'week' (défaut) ou 'month'.

Paramètre / ParameterTypeRequis / RequiredDescription (catalogue)
