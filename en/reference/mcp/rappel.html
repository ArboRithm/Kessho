Recall and reading ​

These tools retrieve what the memory knows: resume a project, read its context, its history or an archive, search the whole vault, summarize the latest sessions, place a repository file and explore a note's links.

None of them writes to the vault: the catalog declares them all read-only.

To ask for them by talking to your agent, see Resume a project and Search the memory.

In practice ​

You ask your agent

« Let's pick up the kessho-docs project again. »

→ The agent callsmem_recall
  • slug = kessho-docs
You ask your agent

« Show me the current context of kessho-docs, without the briefing. »

→ The agent callsmem_read_context
  • slug = kessho-docs
You ask your agent

« Where did we talk about Git synchronization? Search the whole memory. »

→ The agent callsmem_search
  • query = git sync
  • limit = 10
You ask your agent

« Summarize the last five sessions of kessho-docs. »

→ The agent callsmem_digest
  • slug = kessho-docs
  • n = 5
You ask your agent

« Before I change this file, tell me what the memory knows about it: src/domain/session.rs. »

→ The agent callsmem_about_path
  • path = src/domain/session.rs

The tools ​

mem_recall ​

Loads a project's or domain's context to resume a session without a new briefing; without a slug it returns the vault inventory so you can disambiguate.

Catalog description (French, verbatim):

Charge le contexte d'un projet ou d'un domaine pour reprendre une session sans re-briefing. Sans slug, rend l'inventaire du vault pour désambiguïsation.

Paramètre / ParameterTypeRequis / RequiredDescription (catalogue)
slugstringnon / noSlug du projet ou domaine à charger. Omis : inventaire du vault.

mem_read_context ​

Reads the context.md of a project or domain: the current snapshot, lighter than mem_recall because it adds no briefing synthesis.

Catalog description (French, verbatim):

Lit le context.md d'un projet ou d'un domaine. Plus léger que mem_recall : instantané courant sans synthèse de briefing.

Paramètre / ParameterTypeRequis / RequiredDescription (catalogue)
slugstringoui / yesSlug du projet ou domaine.

mem_read_history ​

Reads the history.md of a project or domain: frontmatter, body and the number of session entries detected.

Catalog description (French, verbatim):

Lit le history.md d'un projet ou d'un domaine : frontmatter, corps et nombre d'entrées de session détectées.

Paramètre / ParameterTypeRequis / RequiredDescription (catalogue)
slugstringoui / yesSlug du projet ou domaine.

mem_read_archive ​

Reads one named archive of a project (frontmatter and body); read-only, restricted to the project's archives/ folder.

Catalog description (French, verbatim):

Lit une archive nommée d'un projet : frontmatter et corps. Lecture seule, restreinte au dossier archives/ du projet.

Paramètre / ParameterTypeRequis / RequiredDescription (catalogue)
filenamestringoui / yesNom de l'archive, avec ou sans l'extension .md.
slugstringoui / yesSlug du projet ou domaine.

mem_search ​

Full-text search across the whole vault, one match per line with its context; the query is a regular expression, with options for case, accents, separators, file names, archived content and a result limit.

Catalog description (French, verbatim):

Recherche plein texte dans tout le vault, une correspondance par ligne avec son contexte. Le motif est une expression régulière.

Paramètre / ParameterTypeRequis / RequiredDescription (catalogue)
case_insensitivebooleannon / noIgnorer la casse (vrai par défaut).
fold_accentsbooleannon / noReplier les accents des deux côtés — « reglage » trouve « réglage », « moya zametka » trouve « моя заметка » (vrai par défaut).
fold_separatorsbooleannon / noRendre espaces, tirets et soulignés interchangeables — « deploy kit » trouve deploy-kit, deploy_kit et deploykit. Sans effet sur un motif contenant un métacaractère de regex (vrai par défaut).
include_archivedbooleannon / noInclure 10-episodes/archived/ (exclu par défaut).
limitnumbernon / noNombre maximal de correspondances rendues (défaut 50, max 500).
querystringoui / yesMotif recherché (syntaxe regex).
search_namesbooleannon / noFaire correspondre aussi le NOM du fichier, pour les atomes dont seul le nom porte le motif — « systray » trouve systray.md même si son corps dit « plateau système ». Ces correspondances portent line_number 0 et matched_in_name true (vrai par défaut).
zonestringnon / noRestreint à une zone : 00-inbox, 10-episodes, 20-knowledge…

mem_digest ​

Summarizes the N most recent archives of a project or domain: date, subject and an excerpt of the body.

Catalog description (French, verbatim):

Synthétise les N archives les plus récentes d'un projet ou d'un domaine : date, sujet et extrait de corps.

Paramètre / ParameterTypeRequis / RequiredDescription (catalogue)
from_archivedbooleannon / noAutoriser la synthèse d'un projet archivé (refusé par défaut).
nnumbernon / noNombre d'archives récentes à inclure (défaut 5, max 50).
slugstringoui / yesSlug du projet ou domaine à synthétiser.

mem_about_path ​

Tells you what the vault already knows about a repository file (map facts, the manifest that established its technology, the framing document that concerns it); call it before touching a file you do not know.

Catalog description (French, verbatim):

Rend ce que le vault sait déjà d'un fichier du dépôt, avant qu'on ne le modifie : les faits de carte qui le décrivent, le manifeste qui a établi sa techno, le document de cadrage qui le concerne. À APPELER AVANT de toucher un fichier qu'on ne connaît pas — ce que la mémoire sait ne sert que si on le demande au moment où il compte. Ne rien savoir n'est pas une erreur : la réponse porte alors combien d'atomes du vault citent un fichier quelconque, ce qui distingue « le vault ne sait rien de celui-ci » de « personne ne lui a jamais rien dit ».

Paramètre / ParameterTypeRequis / RequiredDescription (catalogue)
pathstringoui / yesChemin RELATIF à la racine du dépôt, tel qu'on l'écrirait dans un commit : « src-tauri/src/domain/session.rs ». Un chemin absolu est refusé — les atomes citent des chemins relatifs et aucun ne pourrait y correspondre.

mem_relations ​

Explores a note's links in the memory: broader (up), narrower (down) and neighbouring (side) notes, each with its relation type and depth; flags truncated walks, cycles and dangling relations; read-only.

Catalog description (French, verbatim):

Explore les liens d'une note dans la mémoire : ce qui est plus général qu'elle (up : son projet, son domaine, les concepts dont elle relève), ce qui est plus précis (down : ses notes, ses concepts fils) et ce qui lui est voisin (side : les frères du même parent, les notes liées par related ou par un [[lien]]). Chaque relation porte son type (broader, member_of, related, links_to, sibling) et sa profondeur ; un parcours qui dépasse 200 notes est marqué tronque, un cycle est signalé. Les relations déclarées dont la cible n'existe pas ou est ambiguë sont nommées (pendantes). Lecture seule. À APPELER pour situer une note avant de la classer ou de la relier.

Paramètre / ParameterTypeRequis / RequiredDescription (catalogue)
depthintegernon / noProfondeur du parcours, de 1 à 6 (défaut 2).
directionstringnon / noup (plus général), down (plus précis), side (frères et voisins) ou all (défaut).
pathstringoui / yesChemin de la note relatif au vault, avec ou sans .md : « 20-knowledge/runner ».

mem_graph_export ​

Exports the memory graph (notes as nodes with their level and degree, typed relations as edges, plus dangling relations and dead links); session archives are folded into their project by default; read-only.

Catalog description (French, verbatim):

Exporte le graphe de la mémoire : les notes (nœuds, avec leur niveau domaine, concept, projet, note ou archive, et leur degré) et leurs relations (arêtes typées), plus le nombre de relations pendantes et de liens morts. Les archives de session sont repliées par défaut dans leur projet, qui en porte le compte. La charge est volumineuse (de l'ordre de 100 Ko pour 400 notes) : levels ne garde que les niveaux demandés pour la réduire. Lecture seule.

Paramètre / ParameterTypeRequis / RequiredDescription (catalogue)
fold_archivesbooleannon / noVrai (défaut) : replier les archives de session dans leur projet. Faux : les rendre une à une.
levelsarray<string>non / noNe garder que ces niveaux : domaine, concept, projet, note, archive. Absent = tous. Les relations dont un bout est écarté le sont aussi.
