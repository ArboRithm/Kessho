Ingestion ​

These tools bring information into the memory: a free capture (mem), a note, a principle, a goal, a person card, a local document, a codebase-map fact.

They all write. Each one drops its note in its own zone: 00-inbox/ for mem and mem_doc, 20-knowledge/ for notes, 40-principles/, 50-goals/, 60-people/. For mem_note, a name collision is resolved with a suffix, never by overwriting.

To ask for them by talking to your agent, see Write to the memory.

In practice ​

You ask your agent

« Note this down: "A sealed fragment is never edited by hand." »

→ The agent callsmem_note
  • title = Sealed fragment
  • content = A sealed fragment is never edited by hand.
You ask your agent

« Remember this principle, a red line: only document what the code supports. »

→ The agent callsmem_principle
  • title = Only document what the code supports
  • content = A claim that neither the catalog nor the code supports does not belong in the reference.
  • force = red-line
You ask your agent

« Add a short-term goal: publish the documentation by 2026-12-01. »

→ The agent callsmem_goal
  • title = Publish the documentation
  • horizon = short
  • deadline = 2026-12-01
You ask your agent

« Create a card for Claire Martin, a client. »

→ The agent callsmem_person
  • name = Claire Martin
  • relation = client
You ask your agent

« Absorb this document into the memory: /Users/ben/Documents/cahier-des-charges.pdf. »

→ The agent callsmem_doc
  • path = /Users/ben/Documents/cahier-des-charges.pdf
  • title = Cahier des charges

The tools ​

mem ​

Captures free text into the inbox (00-inbox/) when you do not know what kind of note it is; an optional type hint (note, principle, goal, person or idea) guides later sorting.

Catalog description (French, verbatim):

Capture universelle dans 00-inbox/, quand la nature du contenu n'est pas précisée. Un indice de type oriente le classement ultérieur.

Paramètre / ParameterTypeRequis / RequiredDescription (catalogue)
contentstringoui / yesTexte ou Markdown à capturer.
hintstringnon / noIndice de type : note, principle, goal, person ou idea.

mem_note ​

Ingests a knowledge note into 20-knowledge/; a name collision is resolved with a suffix, never by overwriting.

Catalog description (French, verbatim):

Ingère une note de connaissance dans 20-knowledge/. Une collision de nom est résolue par un suffixe, jamais par un écrasement.

Paramètre / ParameterTypeRequis / RequiredDescription (catalogue)
contentstringoui / yesCorps Markdown de la note.
projectstringnon / noProjet de rattachement.
scopestringnon / nowork (défaut), personal ou all.
titlestringoui / yesTitre de la note, qui sert de slug.

Ingère un principe dans 40-principles/{scope}/, avec sa force : red-line, heuristic, value ou action-rule.

mem_codebase ​

Records on a project's codebase map a fact the code does not state by itself (a layer boundary, an invariant, a trap already paid for, a decision), citing the files it describes so it can later be declared stale.

Catalog description (French, verbatim):

Inscrit à la carte d'une codebase un fait que le code ne dit pas de lui-même : ce qui a le droit de traverser quelle couche, un invariant qui tient, un piège déjà payé, une décision qui explique une forme surprenante. À APPELER SUR LE MOMENT, quand tu viens de comprendre quelque chose de coûteux — une demi-heure plus tard le fait est acquis et ne paraîtra plus digne d'être écrit. Consulte d'abord mem_codebase_scan : ses candidats non décrits nomment les fichiers que la carte attend. L'entrée cite les fichiers qu'elle décrit et leurs empreintes sont relevées au disque, ce qui permettra de la déclarer périmée quand ils bougeront. Refusée si elle ne cite aucun fichier sans dire pourquoi.

Paramètre / ParameterTypeRequis / RequiredDescription (catalogue)
aliasesarray<string>non / noLes mots par lesquels un humain cherchera plus tard, en langue VÉCUE et non technique.
bodystringoui / yesPourquoi c'est vrai, et ce que coûte de l'ignorer.
describesarray<string>non / noChemins RELATIFS à la racine du dépôt que cette entrée décrit. Leurs empreintes sont calculées ici en lisant les fichiers — ne les fournis pas. Un chemin absent est refusé : l'entrée naîtrait périmée.
factstringoui / yesLE FAIT, écrit comme il se dit : « la CI ne couvre pas release-kit », jamais « ci ». Il nomme l'atome et c'est par lui qu'on le retrouvera.
projectstringoui / yesSlug du projet dont il est question.
unmeasurable_becausestringnon / noObligatoire SI et seulement si describes est vide : pourquoi ce fait ne se rattache à aucun fichier. Un interdit de conception, par exemple. Sans lui ni describes, l'entrée est refusée.
